# Обновление сайта-портфолио yellow444.github.io

Папка `site_updated/` — полная копия сайта с правками. Чтобы опубликовать:
скопируйте содержимое в свой репозиторий `yellow444.github.io`, проверьте локально,
закоммитьте и запушьте (`git add . && git commit -m "Update CV content" && git push`).
**Я ничего не публиковал автоматически.**

   о руководстве командой и старте карьеры системным администратором.
3. **Опыт.** «Исполком» → «Fullstack-разработчик / тимлид»; добавлены пункты о руководстве командой (5 чел.)
