## Добавление новых статей

1. Скопируйте `articles/template.html` в новый файл, например:

   ```bash
   cp articles/template.html articles/my-article.html
   ```
2. Откройте новый файл и замените текст в элементах `<title>` и `<h1>` на название статьи.
3. Вставьте собственное содержимое внутрь блока `<main>` после заголовка.
4. При необходимости добавьте ссылку на статью в разделе «Статьи» на главной странице.
