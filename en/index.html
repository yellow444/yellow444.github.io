About Me

My name is Maksim Sitnikov — a fullstack .NET developer, DevOps engineer and team lead from Moscow with 8+ years of commercial development. My core stack is C# / .NET 8, ASP.NET Core, React and TypeScript, Python and SQL; in production I work with Docker, Kubernetes, CI/CD and monitoring (Prometheus, Grafana). I love automating processes and sharing knowledge on GitHub and Habr. Currently I work on the backend of the cloud payment system XPay at Xpress Super App.

My projects include a service for submitting applications via the State Services API, image processing tools and libraries for cryptography work. I develop server-side, web and desktop applications and lead them from idea to deployment.

A dedicated focus is data and analytics: designing and maintaining data warehouses, ETL processes and OLAP reporting (Apache Airflow, Kafka, RabbitMQ, Pentaho, Apache Superset, MS Analysis Services). I have led a development team, and started my career as a system administrator — so I'm equally comfortable in the code and in the infrastructure.

I strive to write clean and testable code, build reliable pipelines and believe in the power of automation. In my spare time I participate in hackathons, solve problems on Codewars and raise children — this helps me look at problems from different angles.

More code examples can be found on GitHub, and articles on Habr. I'm always open to new ideas and collaboration.
